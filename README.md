# SPADE supplementary films

[Watch the collection](https://brianzhu1999.github.io/SPADE/)

Ten supplementary films follow observed fields through symbolic equation discovery and predictive tests. The collection covers eight basic partial differential equations, five open-form systems, three-dimensional Euler flow, noisy and sparse observations, and six physical experiments.

The website offers English and Chinese descriptions, remembers the selected language, and supports playback, full-screen viewing, downloads, and direct links to individual films. The video content is in English. Dataset references accompany the corresponding films.

## Website files

- `index.html`, `styles.css`, and `app.js`: the static website.
- `assets/posters/`: ten preview images.
- `assets/videos/`: ten MP4 films, numbered in manuscript order.

The website uses no external JavaScript libraries, web fonts, or analytics. GitHub Pages serves the `main` branch from the repository root.
